# 功能调节

## 功能调节（高度 / 后仰 / 按摩）

本椅子支持高度调节、椅背后仰锁定、腰枕按摩三项功能。

**高度调节**
向上拉起 “升降” 拉杆即可调节椅子高度，到达所需高度后松开 “升降” 拉杆。![Manual02_11](../手册/插图/Manual02_11.jpg)
调节高度时请将身体微微抬离座椅。![Manual02_12](../手册/插图/Manual02_12.jpg)

**椅背后仰功能**
向上拉起 “后仰” 拉杆，椅背角度可随人体动作独立倾斜。![Manual02_13](../手册/插图/Manual02_13.jpg)
向下按下 “后仰” 拉杆，椅背角度即可锁定。将椅背复位至正常位置时请靠在椅背上，否则椅背可能会快速回弹。![Manual02_14](../手册/插图/Manual02_14.jpg)

**按摩功能**
插入 USB 即可启用腰枕的按摩功能。![Manual02_15](../手册/插图/Manual02_15.jpg)

# 常见问题

Q：使用一段时间后扶手变松怎么办？
A：大多数情况下，扶手和椅背的螺丝会在使用一段时间后松动，重新拧紧螺丝即可解决问题。
